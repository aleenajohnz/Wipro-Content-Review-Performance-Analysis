Featured Project

Wipro Content Review Performance Analysis

A data analysis project examining employee performance, productivity, quality, accuracy, attendance, overtime and error rates across a 12-week content review dataset.

Note: This project uses a simulated dataset created for portfolio purposes. It does not contain real employee or company data.

  • Analysed 1,200 records across 12 weeks.
  • Evaluated productivity, quality, accuracy, adherence and overall performance.
  • Analysed employee and team-level performance.
  • Investigated error rates and performance status.
  • Examined relationships between attendance, overtime, productivity and quality.
  • Created 11 data visualisations and a performance dashboard using Python.
